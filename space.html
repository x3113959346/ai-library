怎么用？
  1. 在姿势库点选姿势（可多选，最多 8 个，每个生成一张图）；点卡片即选中，再点一次取消。
  2. 在脸型库选一张脸（不选 = 用你锁定的固定模特），在服装库选一套衣服（不选 = 不指定服装）。
  3. 点右下角「选好了，生成清单」，复制清单粘贴发给我，我就按这个组合生成图片。
  4. 也可以下载 / 复制三联参考图（脸＋服装＋姿势拼在一起），连同清单一起发给我，出图更准。
  5. 所有图片都从原站（姿势 / 脸型 / 服装三个图库站）实时加载，需要联网；个别图片一时加载不出来不影响点选，清单里始终带着原图链接。
分享给别人用（GitHub Pages 部署）
  1. 本站是纯静态页，没有登录和后台，任何普通浏览器打开就能选图、生成提示词清单。
  2. 部署只需把 index.html 和 assets/data/ 里的三个数据文件（pose.js、face.js、costume.js，共约 0.5MB）一起放进 GitHub 仓库 x3113959346/ai-library，保持目录结构不变。
  3. 在仓库 Settings → Pages 里选 Deploy from a branch、分支 main、目录 / (root)，保存后等一两分钟。
  4. 生成的网址形如 https://x3113959346.github.io/ai-library/，把这个网址发给别人即可，不用 Muse、不用登录。
  5. 图片走原站外链，所以仓库里不用放任何图片文件；以后更新数据也只需替换 assets/data/ 里的文件再推送。
